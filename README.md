# miniHackathon275

## Deployment

This project deploys as a static site with GitHub Pages via:

- `.github/workflows/deploy-pages.yml`

### One-time repo setup

1. In GitHub, open **Settings → Pages**.
2. Set **Source** to **GitHub Actions**.

### Deploy trigger

- Push to `main` (or `master`) to auto-deploy.
- Or run the **Deploy static site to GitHub Pages** workflow manually from Actions.
